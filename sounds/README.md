# Звуки из образца

`sounds/ref/*.wav` — короткие фрагменты, вырезанные из ролика-образца, который прислал автор
(48 кГц, 16 бит). Сцена подключает их меткой `ref:имя` (см. `tools/sfx.py`), например
`sfx('ref:lord-breath', f, { who: 'lord' })`.

| файл | что это | где в образце |
|---|---|---|
| `transform-music3.wav` | музыка превращения — присланный трек в обычном темпе, с начала громкой части (0.58 с), 6 с; по умолчанию в `transform(..., { style: 'grow' })`: играет с ухмылки ~4.3 с (две фразы по 2.16 с), громко, последняя 1.2 с плавно затихает (в ролике 08 — 3 с) | отдельный файл |
| `transform-music2.wav` | музыка превращения — присланный автором трек, ускорен в 1.5 раза без смены тона (11.8 с); ролики 03–07 серии | отдельный файл |
| `transform-music.wav` | музыка превращения из первого образца (стерео, 3.1 с); ролики 25–26 | 25.55–28.65 с |
| `grin-hit.wav` | удар при жуткой ухмылке перед превращением | 24.5 с |
| `crack1.wav`, `crack2.wav` | хруст — вырастают руки-лапы | 6.54 с, 6.81 с |
| `lord-breath.wav` | Лорд дышит (5 вдохов: 0, 0.6, 1.17, 1.75, 2.32 с) | 9.05–11.5 с |
| `lord-sing.wav` | Лорд чуть поёт | 11.57–12.3 с |
| `grunt.wav` | «хм!» перед прыжком | 2.5 с |
| `fwip.wav` | свист прыжка | 2.79 с |
| `hit-ow.wav` | удар и «ой» | 2.98 с |
| `impact.wav` | сильный удар | 3.87 с |
| `grin-eee.wav` | «и-и-и» — ухмыляется | 4.62 с |
| `laugh.wav` | смех | 5.1–5.87 с |

# Мир Minecraft и скриншоты фона для двух POV

Каждая половина экрана — это взгляд персонажа. Значит, **камера Minecraft должна стоять на высоте
его глаз и смотреть туда же, куда он**. Ниже — как это настроить и снять. Что строить для каждого
шортса и какие кадры снимать, написано в его сценарии в [shorts/](../shorts/README.md).

## 1. Как выглядят фоны у него

- Обычные текстуры Minecraft с **реалистичными шейдерами**:
  - мягкие тени;
  - солнечные лучи;
  - насыщенные цвета;
  - лёгкая дымка вдали.
- **Задний план размыт** (глубина резкости), персонаж на переднем плане чёткий.
- Сверху лёгкая хроматическая аберрация (цветная кайма по краям) и виньетка. Это добавляется в
  монтажке.

## 2. Подготовка

1. **Minecraft Java Edition** + загрузчик Fabric + мод **Iris** (шейдеры) + шейдерпак
   **Complementary Reimagined** или **BSL** (оба бесплатные).
   - Если в шейдерпаке есть Depth of Field, включите его: фон размоется сам.
   - Если нет, размойте задний план в монтажке.
2. Мир в творческом режиме, команды разрешены. Один раз выполнить:
   ```
   /gamerule doDaylightCycle false
   /gamerule doWeatherCycle false
   /weather clear
   /time set 6000
   ```
   `6000` — полдень, `1000` — утро, `12500` — закат, `18000` — ночь.
3. **F1** прячет интерфейс и руку. **F2** — скриншот (`.minecraft/screenshots`).
4. **FOV 70** для обычных кадров, **80** для взгляда маленьких персонажей: шире угол — и Хэнк
   нависает сильнее. Внутри одной сцены FOV не меняйте.
5. Разрешение окна — максимум, что тянет компьютер: 2560×1440 или 3840×2160.

## 3. Камера на высоте глаз персонажа

Удобнее всего режим наблюдателя (`/gamemode spectator`): можно летать, проходить сквозь блоки и
ставить камеру точно командой

```
/tp @s X Y Z ПОВОРОТ НАКЛОН
```

- **ПОВОРОТ:** 0 = на юг, 90 = на запад, 180 = на север, −90 = на восток.
- **НАКЛОН:** отрицательный — смотрим вверх, положительный — вниз.

Глаза в Minecraft на 1,62 блока выше точки `/tp`. Поэтому:

```
Y = верх блока, на котором стоит персонаж + высота его глаз − 1,62
```

Пример. Персонаж стоит на траве, блок травы на высоте 64, его верх — 65:

| Персонаж | Высота глаз | Y для `/tp` |
|---|---|---|
| Hank | 1,7 | 65 + 1,7 − 1,62 = **65,08** |
| Lid | 0,6 | 65 + 0,6 − 1,62 = **63,98** |
| Granny Moss (стоит) | 0,65 | **64,03** |
| Granny Moss (сидит в кресле) | 1,05 | **64,43** |
| Rocky | 0,55 | **63,93** |
| Pip | 0,3 | **63,68** |

Камера может оказаться «внутри» блока земли — это нормально: в режиме наблюдателя виден мир с
высоты глаз.

**Наклон, чтобы смотреть в лицо собеседнику:**

| Кто → на кого | 1 блок | 1,5 блока | 2 блока | 3 блока |
|---|---|---|---|---|
| Pip → лицо Hank | −50 | −39 | −31 | −22 |
| Hank → Pip | +56 | +45 | +36 | +26 |
| Lid / Rocky → лицо Hank | −42 | −32 | −24 | −17 |
| Hank → Lid / Rocky | +52 | +41 | +33 | +23 |
| Granny (сидит) → Lid | +31 | +22 | +17 | +11 |

## 4. Главный приём: метка вместо персонажа

Чтобы потом правильно нарисовать персонажа по размеру и в перспективе:

1. **Поставьте на место персонажа метку его роста:**
   - Hank — стойка для брони (`/summon armor_stand`), она ровно ~2 блока;
   - Lid — обычный сундук (0,875 блока);
   - Granny и Rocky — маленькая стойка (`/summon armor_stand ~ ~ ~ {Small:1b}`), ~1 блок; персонаж
     чуть ниже неё;
   - Pip — любая плита (0,5 блока).
2. Снимите кадр **с меткой**.
3. Уберите метку и **с той же позиции** (та же команда `/tp`) снимите **чистый** кадр.
4. В монтажке кадр с меткой — подсказка: рисуете персонажа поверх, совпадая по размеру и месту, а
   потом выключаете этот слой.

Команды `/tp` для каждого кадра записывайте в текстовый файл, чтобы вернуться и переснять.

## 5. Из скриншота в половину экрана

- Половина экрана — **1080×960** (почти квадрат 9:8).
- Из скриншота 2560×1440 вырезается центр **1620×1440** и уменьшается до 1080×960. Остаётся запас
  в 1,5 раза для наезда, панорамы и тряски.
- **Главное держите в центре по горизонтали**: края 16:9 обрежутся.

## 6. Какие кадры снимать для каждой точки

Для каждого места, где стоит камера:

1. **Основной кадр.**
2. **Ближе:** на 1 блок ближе к цели. Нужен, когда персонаж «наклоняется» или подходит.
3. **Цели резких поворотов:** тот же `/tp`, но поворот на нужный угол (например, от двери к столу).
4. **Варианты с изменениями:** дверь открыта/закрыта, предмет на месте/пропал, блок сломан.
5. **Для склейки «прошло время»** (ночь, закат) — те же кадры с другим `/time set`.

## 7. Движение камеры без видео

У него камера всё время чуть живёт. Со скриншотами это делается в монтажке:

| Движение | Как сделать |
|---|---|
| Персонаж говорит, камера «дышит» | медленный наезд 100 → 104 % за реплику |
| Подходит или наклоняется | наезд 100 → 130 % за 0,3–0,5 с или переход на кадр «ближе» |
| **Резкий поворот** (у него на каждом взгляде в сторону) | 3–5 кадров: сдвиг + motion blur + переход на кадр-цель, плюс звук свиста |
| Бег | тряска 4–8 px каждый кадр + покачивание вверх-вниз + наезд |
| Прыжок Pip | камера Pip подскакивает вверх-вниз по дуге |
| Испуг, удар | короткая сильная тряска 2–3 кадра, иногда красная вспышка |

Настоящее 3D-движение (пролёт, бег по дому) можно записать модом **Replay Mod** (бесплатный): ставите
точки пути камеры и рендерите видео. Это необязательно, скриншотов достаточно.

## 8. Чтобы персонажи «стояли» в мире

- **Свет одинаковый:** все кадры сцены снимайте за один раз, с одним временем суток и одними
  настройками.
- **Тень под персонажем:** мягкий тёмный эллипс, 15–20 % непрозрачности.
- **Подкрашивание под свет сцены:**
  - на закате — тёплый оранжевый слой «умножение» 10–15 %;
  - ночью и в пещере — синий 20–30 %;
  - в Незере — красный.

  У него в синем замке персонажи заметно синие.
- **Размытие:** если фон размыт, персонаж на дальнем плане тоже чуть размыт.

## 9. Пост-обработка всего кадра, как у него

- Хроматическая аберрация: 1–2 px, сильнее к краям.
- Лёгкая виньетка.
- Насыщенность +10 %.
- Водяной знак канала в правом верхнем углу, полупрозрачный.

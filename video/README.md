# «If Your Robot Vacuum Ever Stops Next To Your Bed… DO NOT GET UP»

Ролик в формате канала [@BradikininVideos](https://www.youtube.com/@BradikininVideos): 5:48, 1920×1080,
30 к/с, английская озвучка, субтитры по словам. Всё — графика, голос, музыка и шумы — собирается кодом
из этой папки.

**Формула сценария.** Заголовок «If your X ever does Y… DO NOT Z». Холодное начало из трёх «не делайте»,
затем «There are seven rules» и загадка про седьмое. Семь правил, в каждом есть реальный факт (исследование,
судебное дело, новость), подкрученный в жуть. Рассказчик — «trusted government agency»: спокойный,
канцелярский, с оговорками вроде «Apologies. That was unprofessional». В седьмом правиле поворот:
агентство само оказывается частью аномалии. Финал — «Thank you for your cooperation» и одно слово
(«Stay.», «Sleep.», «Wait.»).

**Картинка.** Чёрный фон, белые пиктограммы как на табличках, красные кресты и акценты, зелёные
галочки. Субтитры капсом по центру снизу. Шапка «FILE 041 // BRADIKININ», счётчик правил 1–7, таймкод.
Глитч-переходы, лёгкое свечение, зерно.

**Звук.** Спокойный низкий мужской голос (основной тон около 100–145 Гц), непрерывный тёмный эмбиент,
низкие удары на карточках правил, глитч-шумы.

## Что сделано лучше

- **Динамика.** Около 50 сцен вместо статичных картинок: персонажи с суставами (садятся, ходят, несут
  пылесос), лидар, который проявляет квартиру точками, рамки распознавания, штампы, окна приложения,
  наезды и проезды камеры. Каждое действие привязано к конкретному слову диктора.
- **Субтитры** появляются по словам вместе с голосом, ключевые слова горят красным.
- **Своя айдентика** вместо копии: «Office of Domestic Continuity», эмблема с «глазом», который в
  финале оказывается пылесосом, карточки правил другой вёрстки, рамка видоискателя.
- **Звуковой дизайн** на каждое действие: около 290 событий, 40 видов эффектов, своя тема-колыбельная
  и подложка с приглушением под голос, громкость −14 LUFS (норма YouTube).
- **Факты проверены** (все с источниками в прессе): первый Roomba вышел в 2002;
  в 2017 глава iRobot говорил Reuters о передаче карт домов партнёрам «с согласия»; iRobot обанкротилась
  в декабре 2025, её купил производитель Picea; гарантия P.O.O.P. (Pet Owner Official Promise) у Roomba j7;
  Чханвон, 2015 — пылесос засосал волосы спящей на полу женщины, вызывали спасателей; LidarPhone
  (Мэрилендский университет и NUS, 2020) — подслушивание через лидар, ~90 % точности на цифрах;
  Georgia Tech, 2007 — 21 из 30 владельцев дали Roomba имя; MIT Technology Review, 2022 — снимки
  тестовых Roomba J7, включая женщину в туалете, утекли в закрытые группы Facebook; 2024 — взломанные
  Ecovacs Deebot X2 кричали на хозяев в нескольких городах США и гонялись за собаками.

## Сборка

Нужны Python 3.11+, ffmpeg и пакеты из `requirements.txt` (для skia-python в Linux нужен `libegl1`).

```bash
pip install -r requirements.txt
python tts.py        # голос → build/voice.wav и build/timeline.json (тайминги слов)
python sound.py      # музыка и эффекты → build/mix.wav
python render.py     # видео → out/video.mp4 (4 процесса)

python render.py --stills 12.5,95,300   # отдельные кадры для проверки → out/sheet.png
python render.py --from 60 --to 80      # кусок → out/preview.mp4
```

Голос — бесплатный нейросетевой `en-US-ChristopherNeural` через edge-tts. Другой голос:
`python tts.py --voice en-US-AndrewMultilingualNeural --rate -4%`, затем снова `sound.py` и `render.py`
(сцены сами подстроятся под новые тайминги). За прокси с собственным сертификатом:
`EDGE_CA_BUNDLE=/path/ca.crt python tts.py`.

## Шрифт

Все надписи — **Lucida Sans Unicode**. Файла в репозитории нет (шрифт Microsoft): положите `l_10646.ttf`
из `C:\Windows\Fonts` в `fonts/` и пересоберите видео. Пока файла нет, используется DejaVu Sans.

## Файлы

| Путь | Что это |
|---|---|
| `script.py` | сценарий: реплики, акценты, паузы, карточки правил |
| `tts.py` | озвучка, тайминги слов, обработка голоса |
| `scenes.py`, `scenes2.py` | все сцены по порядку, привязанные к словам; звуковые метки |
| `engine/core.py` | палитра, шрифты, плавность движений, трансформации |
| `engine/picto.py` | пиктограммы: люди с суставами, пылесос, станция, мебель, иконки, эмблема |
| `engine/mapplan.py` | план квартиры и лидарное сканирование |
| `engine/kit.py` | улики, рамки распознавания, штампы, окна, облачка, осциллограмма |
| `engine/hud.py` | шапка, счётчик правил, субтитры, карточки правил и титр |
| `engine/fx.py` | свечение, глитч, аберрация, зерно, виньетка |
| `engine/stage.py` | шкала времени, переходы, тряска, вспышки |
| `sound.py` | синтез музыки и эффектов, сведение |
| `render.py` | рендер кадров и сборка mp4 |

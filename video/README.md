# Ролики в стиле @BradikininVideos

Анимационные ролики в формате канала [@BradikininVideos](https://www.youtube.com/@BradikininVideos):
«семь правил» от лица спокойного «правительственного агентства». Всё — графика, голос, музыка
и шумы — собирается кодом из этой папки. Агентство у нас своё: **Office of Domestic Continuity**,
дела идут по номерам.

| Дело | Ролик | Длина | Папка |
|---|---|---|---|
| FILE 017 | If Your Robot Vacuum Ever Stops Next To Your Bed… DO NOT GET UP | 5:48 | `films/vacuum/` |
| FILE 018 | If You Ever Hear Someone Downstairs At Night… DO NOT GO DOWN | 8:17 | `films/burglar/` |

Оба ролика: 1920×1080, 30 к/с, английская озвучка, субтитры по словам, звук −14 LUFS.

## Что взято у канала

Разобраны все 5 роликов канала (просмотры на 17.10.2026):

| Ролик | Просмотры | Длина |
|---|---|---|
| If Your Dog Ever Stands On Two Legs… ACT NORMAL | 1,6 млн | 4:33 |

| If Your Old Phone Ever Rings With No SIM Card… DO NOT ANSWER | 477 тыс. | 5:43 |
| If Your Phone Ever Charges To 101%… DO NOT UNPLUG IT | 292 тыс. | 4:41 |
| If You Ever Get GTA 6 Before It Comes Out… DO NOT LEAK IT | 66 тыс. | 5:34 |

**Формула сценария.** Заголовок «If your X ever does Y… DO NOT Z». Холодное начало из трёх «не делайте»,
затем «There are seven rules» и загадка про седьмое. Семь правил, в каждом есть реальный факт (исследование,
судебное дело, новость), подкрученный в жуть. Рассказчик — «trusted government agency»: спокойный,
канцелярский, с оговорками вроде «Apologies. That was unprofessional». В седьмом правиле поворот:
агентство само оказывается частью аномалии. Финал — «Thank you for your cooperation» и одно слово.

**Картинка.** Чёрный фон, белые пиктограммы как на табличках, красные кресты и акценты, зелёные
галочки. Субтитры капсом по центру снизу. Шапка с номером дела, счётчик правил 1–7, таймкод.
Глитч-переходы, лёгкое свечение, зерно.

**Звук.** Спокойный низкий мужской голос, непрерывный тёмный эмбиент, низкие удары на карточках
правил, глитч-шумы.

## Что сделано лучше

- **Динамика.** 50–65 сцен на ролик вместо статичных картинок: персонажи с суставами (садятся, ходят,
  толкают комод, несут пылесос), разрез двухэтажного дома, где одновременно видно героя наверху и
  грабителя с фонарём внизу, лидар, который проявляет квартиру точками, рамки распознавания, штампы,
  экраны телефона, наезды и проезды камеры. Каждое действие привязано к слову диктора.
- **Субтитры** появляются по словам вместе с голосом, ключевые слова горят красным.
- **Своя айдентика:** «Office of Domestic Continuity», эмблема с «глазом» (в первом ролике он
  оказывается пылесосом), свои карточки правил и рамка видоискателя.
- **Звуковой дизайн** на каждое действие: 230–290 событий на ролик, около 60 видов эффектов, у каждого
  ролика своя тема-колыбельная и тональность, музыка приглушается под голос.
- **Полезность.** Во втором ролике правила — реальные советы полиции (не спускаться, запереться,
  звонить молча: 999 + 55 в Британии, SMS на 911 в США), а жуть — в деталях и в финале.

### Факты (проверены по прессе)

**FILE 017, пылесос.** Первый Roomba вышел в 2002; в 2017 глава iRobot говорил Reuters о передаче карт
домов партнёрам «с согласия»; iRobot обанкротилась в декабре 2025, её купил производитель Picea;
гарантия P.O.O.P. у Roomba j7; Чханвон, 2015 — пылесос засосал волосы спящей на полу женщины; LidarPhone
(Мэриленд и NUS, 2020) — подслушивание через лидар, ~90 % на цифрах; Georgia Tech, 2007 — 21 из 30
владельцев дали Roomba имя; MIT Technology Review, 2022 — снимки тестовых Roomba J7 утекли в закрытые
группы Facebook; 2024 — взломанные Ecovacs Deebot X2 кричали на хозяев и гонялись за собаками.

**FILE 018, грабитель.** Бюро судебной статистики США (2003–2007): в 28 % краж со взломом кто-то был дома,
в 7 % всех краж на жильцов нападали или угрожали им; «hot prowl» — полицейский термин для кражи при
хозяевах; британская Silent Solution (999, затем 55); «call if you can, text if you can't» — совет FCC
о SMS на 911; Касуя, префектура Фукуока, 2008 — женщина около года жила на верхней полке шкафа у
мужчины, который заметил пропажу еды и поставил камеры; термин «phrogging»; UNC Charlotte, 2012 —
опрос 422 заключённых грабителей, ~60 % обошли бы дом с сигнализацией; Ред-Хаус, Западная Вирджиния —
хозяин нашёл в своей кровати спящего взломщика, и тот спал до приезда полиции.

## Сборка

Нужны Python 3.11+, ffmpeg и пакеты из `requirements.txt` (для skia-python в Linux нужен `libegl1`).
Все команды принимают `--film vacuum` или `--film burglar`.

```bash
pip install -r requirements.txt
python tts.py --film burglar        # голос → build/burglar/voice.wav и timeline.json (тайминги слов)
python sound.py --film burglar      # музыка и эффекты → build/burglar/mix.wav
python render.py --film burglar     # видео → out/burglar/video.mp4 (4 процесса)
python thumbnail.py --film burglar  # обложка → out/burglar/thumbnail.png

python render.py --film burglar --stills 12.5,95,300   # кадры для проверки → out/burglar/sheet.png
python render.py --film burglar --from 60 --to 80      # кусок → out/burglar/preview.mp4
```

Если в сценарии задан `TARGET` (секунды), `tts.py` подгоняет паузы так, чтобы ролик длился ровно
столько: второй ролик ровно 8:17.

Голос — бесплатный нейросетевой `en-US-ChristopherNeural` через edge-tts. Другой голос:
`python tts.py --film burglar --voice en-US-AndrewMultilingualNeural`, затем снова `sound.py` и
`render.py` (сцены сами подстроятся под новые тайминги). За прокси с собственным сертификатом:
`EDGE_CA_BUNDLE=/path/ca.crt python tts.py ...`.

## Шрифт

Все надписи — **Lucida Sans Unicode**. Файла в репозитории нет (шрифт Microsoft): положите `l_10646.ttf`
из `C:\Windows\Fonts` в `fonts/` и пересоберите видео. Пока файла нет, используется DejaVu Sans.

| Путь | Что это |

| `films/<ролик>/thumb.py`, `youtube.md` | обложка; название, описание и источники для YouTube |

| `engine/house.py` | разрез двухэтажного дома |
| `engine/mapplan.py` | план квартиры и лидарное сканирование |
| `engine/kit.py` | улики, рамки распознавания, штампы, окна, облачка, осциллограмма |
| `engine/hud.py` | шапка, счётчик правил, субтитры, карточки правил и титр |
| `engine/fx.py` | свечение, глитч, аберрация, зерно, виньетка |
| `engine/stage.py` | шкала времени, переходы, тряска, вспышки |
| `tts.py`, `sound.py`, `render.py`, `thumbnail.py` | озвучка, звук, рендер, обложка |

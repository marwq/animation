# Шрифты

Все надписи в ролике — **Lucida Sans Unicode**. Это шрифт Microsoft, его нельзя класть в репозиторий,
поэтому файла здесь нет. Положите сюда `l_10646.ttf` (Windows: `C:\Windows\Fonts\l_10646.ttf`) —
движок подхватит его сам. У Lucida Sans Unicode одно начертание, жирные заголовки получаются
программным утолщением.

Пока файла нет, используется DejaVu Sans (`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`, лицензия в
`LICENSE-DejaVu.txt`).

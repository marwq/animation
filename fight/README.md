# Драки «animal hospital long»

Ролики-драки в жанре «Animation Battles» (как у @HugyTi) из ригов автора в Moho.
Рендер идёт прямо из `.moho`-файлов: слои, заливки и обводки берутся из рига, части
вращаются вокруг кругляшей на суставах.

## Ролики

| Ролик | Фон | Что происходит |
|---|---|---|
| `export/skeleton_vs_lord.mp4` | пустынный каньон, день | Шарики сталкиваются лбами, скелет отлетает и превращается в крылатого, лорд тоже. Лорд бросает шляпу-фрисби, скелет ныряет, шляпа бумерангом бьёт его по затылку и возвращается лорду. Скелет подлетает, ныряет под шлепок и апперкотом отправляет лорда за кадр. Победил скелет. |
| `export/pink_vs_la_peace.mp4` | луг с холмами и блочными деревьями, день | Ла Пис подплывает к розовой-шарику и гладит бороду. Она дважды бросается на него — ладонь в лоб, потом шлепок снизу, и она падает блином. Злится и превращается в большую, шлёт Ла Пису воздушный поцелуй — он влюбляется; прибегают лорд и скелет, тоже влюблённые. Скелет толкает лорда — лорд отправляет его вправо; лорд отпихивает Ла Писа — тот ладонью отправляет лорда вверх; Ла Пис лезет к розовой — пощёчина, и он улетает вдаль. Победила розовая. |

Формат: 1920×1080, 24 fps, 25 с (600 кадров), H.264, без звука и без надписей.
В первом ролике первые 4 с — стойка (место под 3‑2‑1); со второго ролика начало не статичное — по просьбе автора, первые секунды кто-то двигается.

## Как пересобрать

```bash
pip install pycairo
python3 render.py skeleton_vs_lord                      # видео → export/skeleton_vs_lord.mp4
python3 render.py skeleton_vs_lord --sheet 0 600 6      # лист кадров каждые 0,25 с
python3 render.py skeleton_vs_lord --frames 135 458     # отдельные кадры в PNG
```

Нужен `ffmpeg` в PATH. Если поменять риг в Moho и положить его в `rigs/`, изменения
попадут в ролик при следующем рендере.

## Файлы

| Файл | Что внутри |
|---|---|
| `rigs/*.moho` | риги автора (zip с `Project.mohoproj`), в том числе `la_peace.moho` |
| `moho.py` | чтение рига: кривые Moho → кривые Безье, фигуры, обводки, переключатели |
| `rig.py` | точки вращения частей, позы, IK ног (колени всегда вперёд) и рук (точно в точку) |
| `anim.py` | ключи поза‑на‑позу, прыжки шариков, ходьба без скольжения, камера |
| `fx.py` | искра, пыль, дым, звёздочки, пот, жилка злости, пар, лучи, блеск, «вжух», тень |
| `bg.py` | фоны (каждый ролик — своя локация) и плывущие пиксельные облачка |
| `film_<имя>.py` | раскадровка одного ролика |
| `render.py` | рендер в MP4 и листы кадров для проверки |

# Шортс: La Peace раскручивает Verity на качелях

| Файл | Что это |
|---|---|
| `verity-swing.mp4` | готовый ролик 1080×1920 (9:16): музыка, эффекты, озвучка |
| `verity-swing-no-vo.mp4` | тот же ролик без рассказчика: музыка, эффекты и крик Verity |
| `build_sound.py` | весь звук: музыка (MIDI → FluidSynth), синтез эффектов, сведение, мастер |
| `tts_lines.py`, `lines.json` | генерация дублей озвучки клоном голоса (Chatterbox TTS) |
| `vo/*.wav` | выбранные дубли; в `yell.wav` от дубля «Lah Peace! Noooo!» оставлено только «NOOO!» (с 1.85 с) |

Исходник был 1920×1080 — тот же кадр 9:16, повёрнутый на 90°. Здесь он развёрнут
обратно (`transpose=1`).

## Озвучка

Голос — клон присланного образца (англоязычный дикторский стиль: короткие фразы,
вопрос → ответ одним словом). Имя в тексте для TTS написано как «Lah Peace», чтобы
звучало «Ла Пис».

| Время | Реплика | Картинка |
|---|---|---|
| 0.02 | *La Peace pushed Verity on the swing.* | La Peace обматывает Verity цепью |
| 2.30 | *Speed?* | качели сорвались вниз |
| 3.05 | *Max.* | первый быстрый круг |
| 4.21 | Verity: *NOOO!* (выше по тону, улетает, у камеры снова громко) | запуск, пролёт мимо камеры |
| 4.87 | *Signal?* | склейка в космос — крик обрывается |
| 5.40 | *Lost.* | наезд на испуганное лицо |

## Звук по таймлайну

Сетка музыки — 107.14 BPM, доля 0.56 с от 0.24 с: быстрые круги качелей (низ в 3.04,
3.32, 3.60, 3.88, 4.16) — ровно восьмые, запуск — на долю.

- **0–2.5** — «на цыпочках»: пиццикато и фагот в ре миноре; звон цепей, щелчок замка,
  «блик» на хитрый прищур, телефон из кармана, тык по экрану; качели поднимаются,
  скрипят наверху, арфа вниз на падении.
- **2.5–4.16** — разгон: литавра, писк ползунка скорости, галоп (туба, струнные,
  ксилофон вверх, барабаны), свист на каждом круге, нарастание.
- **4.16** — удар оркестра и музыка обрывается: «бо-о-инг», свистулька вверх, ветер,
  пролёт мимо камеры.
- **4.86–5.88** — космос: глухой удар, хор и пэд с длинным эхом, челеста, радиописк,
  шум «потери сигнала» и низкий «бум» на *Lost.*

Мастер: −14 LUFS (норма YouTube), пик −1.5 dBFS.

## Как пересобрать

```bash
sudo apt install fluidsynth fluid-soundfont-gm sox ffmpeg
pip install numpy scipy soundfile mido pyloudnorm

python3 build_sound.py build/            # build/mix.wav
python3 build_sound.py build/ --no-vo    # build/mix_no_vo.wav

ffmpeg -i исходник.mp4 -i build/mix.wav -map 0:v -map 1:a \
  -vf "transpose=1,scale=in_range=pc:out_range=tv:in_color_matrix=bt601:out_color_matrix=bt709,format=yuv420p" \
  -c:v libx264 -preset slow -crf 18 -colorspace bt709 -color_primaries bt709 \
  -color_trc bt709 -color_range tv -c:a aac -b:a 256k -movflags +faststart -t 5.88 verity-swing.mp4
```

Новые дубли озвучки (Python 3.11, `pip install chatterbox-tts "setuptools<81"`):

```bash
python3 tts_lines.py образец.wav out/ lines.json
```

# 08. Granny vs. Lid

| | |
|---|---|
| Длина | ~14 с |
| Персонажи | Granny Moss, Lid |
| Название | He Tried to Scam GRANNY 👵🔥 (Minecraft Animation) #shorts |
| **Верх** | глаза Lid (0,6 блока, смотрит снизу на крыльцо) |
| **Низ** | глаза Granny (сидит в кресле-качалке, ~1,05 блока) |

**Идея.** Lid выдаёт себя за «волшебный сундук желаний»: «Дай один изумруд — верну два». Granny
мило соглашается и кладёт в него печенье. Это её фирменное печенье с чили. Lid краснеет, свистит
паром из замочной скважины, выпускает струю огня и с визгом скачет в пруд. Granny отпивает чай:
«Kids these days.»

**Приём.** Контраст тона и действия. Granny ни разу не повышает голос. О подвохе зритель узнаёт по
вспышке на её очках чуть раньше Lid.

## Мир: что построить

**Крыльцо домика Granny Moss на закате** (`/time set 12500`):
- еловый пол крыльца, крыша на заборах;
- **кресло-качалка** (ступенька + люки по бокам);
- маленький столик с чайником (горшок) и тарелкой печенья (дорисовать);
- фонари, цветы в горшках;
- **в 6–8 блоках от крыльца небольшой пруд**.

## Озвучка

```
LID     [fast, slick salesman]          Evening, ma'am! Magic wishing chest! One emerald in — TWO out!
GRANNY  [slow, sweet, shaky]            Oh, how lovely, dearie.
LID     [chewing, then confused]        Mmm... wait. That's not an emerald.
GRANNY  [sweet, calm]                   It's my famous chili cookie, dearie.
LID     [strained, rising pitch]        Hot. Hot. HOT!
LID     [high-pitched scream]           AAAAAH!
GRANNY  [sweet, sipping tea]            Kids these days.
```

**Субтитры:**
- Lid виден внизу → золотой текст у верхнего края нижней половины.
- Granny видна вверху → белый у нижнего края верхней.
- «TWO», «HOT», «AAAAAH» — заглавными.

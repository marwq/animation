# 01. Who Ate Hank's Birthday Cake?

| | |
|---|---|
| Длина | ~10,5 с |
| Персонажи | Hank, Pip |
| Название | Who Ate Hank's Birthday Cake? 🎂 (Minecraft Animation) #shorts |
| **Верх** | глаза Pip (0,3 блока, снизу вверх) |
| **Низ** | глаза Hank (1,7 блока, сверху вниз) |

**Идея.** У Хэнка день рождения, но торт пропал. Pip уверяет: «What cake?» Хэнк смотрит вниз —
торт целиком лежит внутри прозрачного Pip. Хэнк втыкает свечку прямо Pip в голову и поёт себе
«Happy birthday» без всякого энтузиазма.

**Приём.** Улика всё время видна в нижней половине (глаза Хэнка). Зритель понимает всё сразу, Pip
не понимает ничего. Последняя строка — та же песенка, что и первая, поэтому ролик закольцован.

## Мир: что построить

**Одна комната в доме Хэнка, день:**
- пол из еловых досок, стены из дубовых;
- окно (стеклянная панель) с дневным светом;
- красная кровать в углу;
- дубовая дверь на стене напротив стола;
- в центре стол: дубовый забор + нажимная плита сверху. Можно любой «стол», главное — пустой.

Крошки и тарелку дорисовать.

## Озвучка

```
HANK  [proud, loud, sing-song]          Happy birthday to ME!
HANK  [slow, suspicious, lower]         Pip... where's my cake?
PIP   [sweet, innocent, high]           What cake?
HANK  [deadpan, flat, ~100 Hz]          The one INSIDE you.
PIP   [tiny, guilty]                    ...Surprise?
HANK  [flat, joyless singing]           Happy birthday... to me.
```

**Субтитры:**
- Хэнк виден вверху → его текст у нижнего края верхней половины (оранжевый).
- Pip виден внизу → у верхнего края нижней (розовый).
- «INSIDE» — заглавными.

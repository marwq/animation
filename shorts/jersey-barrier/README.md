# Short: почему бетонные разделители скошены у основания

28 секунд, 1080×1920, 24 к/с, английская озвучка. Сценарий, факты и источники — в [script.md](script.md).

Всё собирается кодом: 3D — Blender (Cycles, CPU), голос — Chatterbox TTS по образцу голоса,
звук — синтез + записи CC0, субтитры — ASS, сборка — ffmpeg.

## Файлы

| Путь | Что это |
|---|---|
| `scene.py` | окружение (две раскладки шоссе), материалы, процедурные седан и внедорожник, пулы частиц |
| `shots.py` | хореография 9 планов: замедления (`TM`), физика машин и обломков, камеры, рендер |
| `events.json` | моменты ударов и смен планов в секундах ролика (`shots.events()`), нужны звуку и монтажу |
| `voice/lines.txt`, `voice/takes/` | реплики и сгенерированные дубли |
| `voice/timeline.json` | где начинается каждая реплика и когда звучит каждое слово |
| `audio.py` | шумовые эффекты, музыка, сведение с голосом → `mix.wav` |
| `subs.py` → `subs.ass` | субтитры, плашка с датой, финальный титр |
| `assemble.sh` | кадры + звук + субтитры → mp4 |
| `fetch_assets.sh` | скачать небо, текстуры, звуки и шрифт (все CC0 / OFL) |

## Как пересобрать

```bash
./fetch_assets.sh /path/to/assets
export ASSETS=/path/to/assets

# 3D: нужен модуль bpy (pip install bpy, Python 3.13)
python shots.py -- out/test test              # по 5 пробных кадров на план, 360×640
python shots.py -- out/render render          # все кадры 720×1280, ~4 ч на 4 ядрах CPU

# голос: Chatterbox (Python 3.11, torch CPU) по образцу ref.wav, затем тайминг слов (faster-whisper)
python voice/tts.py ref.wav voice/lines.txt voice/takes 0.7 0.4 7
python voice/make_timeline.py

python audio.py voice out/mix.wav             # нужен librosa, pyloudnorm, scipy
python subs.py > subs.ass
./assemble.sh out/render out/mix.wav $ASSETS/fonts jersey-barrier.mp4
```

В описание ролика: «3D animation. Real crashes depend on speed, angle and the vehicle.»

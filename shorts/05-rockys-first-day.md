# 05. Rocky's First Day

| | |
|---|---|
| Длина | ~12 с |
| Персонажи | Rocky, Hank, Granny Moss |
| Название | The Worst Guard EVER 🛡️ (Minecraft Animation) #shorts |
| **Верх** | глаза Rocky (0,55 блока) |
| **Низ** | глаза Hank (1,7 блока) |

**Идея.**
1. Granny велит Rocky никого не пускать в огород. Приходит Хэнк с мешком.
2. Rocky: «Password?» Хэнк: «…There's no password.» Rocky: «Correct!» — и открывает калитку.
3. Хэнк идёт к гигантским тыквам. Granny из окна дёргает рычаг, поршень запускает Хэнка в небо.
4. Rocky отдаёт честь: «Have a nice day, sir!»

**Приём.** Буквальная логика стражника (фирменная фраза Rocky на будущее). И бабушка, которая
сильнее всех: её медленное «Oh, dearie…» заранее говорит зрителю, что сейчас будет.

## Мир: что построить

**Огород Granny Moss, день.**
- **Домик:**
  - стены из замшелого булыжника и ели;
  - крыша с ковром из мха;
  - фонарь и цветочные горшки;
  - окно, выходящее на огород;
  - **рычаг на стене у окна**.
- **Огород:**
  - дубовый забор с калиткой;
  - внутри гигантские тыквы (2×2 из тыкв), арбузы, морковь;
  - **перед тыквами под травой спрятан поршень** — это «катапульта».
- Снаружи у калитки тропинка.

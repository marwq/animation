# 03. Pip Ate the TNT

| | |
|---|---|
| Длина | ~11 с |
| Персонажи | Hank, Pip |
| Название | Pip Ate the TNT… 💥 (Minecraft Animation) #shorts |
| **Верх** | глаза Pip (0,3 блока) |
| **Низ** | глаза Hank (1,7 блока) |

**Идея.** Из стопки пропал один TNT. Хэнк смотрит вниз: TNT внутри Pip, и он мигает. Хэнк убегает,
Pip радостно скачет за ним. Вспышка. Оба в саже, Pip в восторге: «Again!»

**Приём.** Погоня в двух POV: в половине Хэнка мы оглядываемся на мигающего Pip, в половине Pip —
догоняем убегающего Хэнка. Взрыв не показываем, только белую вспышку и звон.

## Мир: что построить

**Двор перед домом Хэнка, день:**
- рядом с домом вход в шахту в склоне холма (рамка из дубовых брёвен);
- у входа стопка TNT 2×2, **без одного блока**;
- табличка «HANK'S TNT — DO NOT EAT»;
- от двора в поле уходит тропинка (для бега);
- для финала ямка: убрать 3–4 блока травы, поставить каменистую землю.

## Озвучка

```
HANK  [annoyed, loud]                    Who took my TNT?!
PIP   [cheerful, high]                   Hiii, Hanky!
HANK  [very quiet, slow, terrified]      Pip... spit it out. Slowly.
PIP   [innocent, head tilt]              Spit what?
HANK  [shout]                            NOPE!
PIP   [happy, bouncing]                  Hanky, wait for me!
HANK  [long scream]                      NOOOO!
PIP   [delighted]                        Again!
```

Можно добавить в самом конце, на 0,5 с: **HANK** (слабо, лёжа): «…no.»

**Субтитры:**
- Хэнк виден вверху → оранжевый текст у нижнего края верхней половины.
- Pip виден внизу → розовый у верхнего края нижней.
- «NOPE», «NOOOO» — заглавными, крупнее.

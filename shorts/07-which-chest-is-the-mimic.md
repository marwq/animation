# 07. Which Chest Is the Mimic? (Challenge)

| | |
|---|---|
| Длина | ~12 с |
| Персонажи | Hank, Pip, Lid |
| Название | Which Chest Is the Mimic? 🤔 (Minecraft Animation Challenge) #shorts |
| **Верх** | глаза Pip (0,3 блока) |
| **Низ** | глаза Hank. **Он стоит на сундуке**, поэтому глаза на ~2,5 блока |

**Идея.**
1. Хэнк и Pip стоят перед двумя одинаковыми сундуками: «One of these is Lid.»
2. Пауза-челлендж: «TOP or BOTTOM?»
3. Оба сундука обычные: в одном печенье, в другом изумруды.
4. Хэнк смотрит под ноги: он **всё это время стоит на Lid**. ЧОМП.
5. Pip надевает упавшую каску Хэнка: «Can I be the boss now?»

**Приём.** Челлендж: зритель выбирает, комментирует, ошибается. **Пасхалка для пересмотра:** на
0:02 в половине Pip сундук под Хэнком моргает один раз. Закреплённый комментарий: «Did you
notice the blink at 0:02? 👀»

## Мир: что построить

**Кладовая Хэнка:**
- комната из каменного кирпича;
- 2–3 факела на стенах;
- бочка и верстак у стены;
- на полу **два одинаковых сундука** рядом, между ними 1 блок;
- **третий сундук** в 1,5 блока позади них — на нём стоит Хэнк.

Открытые крышки и содержимое дорисовать: в Minecraft сундук открыт только вместе с окном
инвентаря.

## Озвучка

```
HANK  [serious whisper]                 Pip. One of these is Lid.
PIP   [excited]                         Which one?!
HANK  [commanding]                      Open yours. I'll open mine.
PIP   [happy]                           Cookies!
HANK  [happy]                           Emeralds!
HANK  [confused, slowing down]          Huh... then where is—
LID   [cheerful, from below]            Hi, buddy!
PIP   [thrilled, hat on]                Can I be the boss now?
```

**Текст челленджа** белый, крупный (~90 px), по центру поверх линии разреза. Так это сразу
читается как «вопрос к зрителю», а не как реплика.

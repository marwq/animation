# 04. Free Diamonds Inside

| | |
|---|---|
| Длина | ~12,5 с |
| Персонажи | Hank, Lid, Pip (в конце) |
| Название | NEVER Open This Chest 😳 (Minecraft Animation) #shorts |
| **Верх** | глаза Lid (0,6 блока, у земли, смотрит вверх) |
| **Низ** | глаза Hank (1,7 блока) |

**Идея.** На тропе стоит сундук с табличкой «FREE DIAMONDS». Сундук говорит. Хэнк сомневается
ровно секунду, тянется к нему — и сундук его съедает. Внутри темно, а в углу сидит довольный Pip с
алмазом: «Since Tuesday!»

**Приём.** Двойной поворот: сначала «сундук — монстр» (зритель ждёт), потом «внутри уже кто-то
есть» (не ждёт). А Lid снаружи как ни в чём не бывало зовёт следующую жертву: «Psst! Hey,
buddy!» — ролик закольцован.

## Мир: что построить

1. **Лесная тропа на закате** (`/time set 12500`): большой дуб у тропы, под ним место для сундука
   и табличка «FREE DIAMONDS».
2. **«Внутри сундука»** — отдельная маленькая постройка где угодно:
   - комнатка 3×2×3 из досок тёмного дуба;
   - один тусклый источник света, будто через замочную скважину (фонарь за люком);
   - на стене табличка «NO REFUNDS»;
   - в углу пусто: там сидит Pip, он дорисован.

## Озвучка

```
HANK  [reading, greedy, slow]           Free... diamonds?
LID   [whisper, slick salesman, fast]   Psst! Hey, buddy! Free diamonds inside!
HANK  [suspicious]                      Chests don't talk.
LID   [quick, cheeky]                   Diamonds do!
HANK  [instantly convinced]             ...Fair enough.
PIP   [delighted]                       Hi, Hanky! I got a diamond!
HANK  [muffled, deadpan]                How long have you been in here?
PIP   [proud]                           Since Tuesday!
LID   [cheerful, next victim]           Psst! Hey, buddy!
```

**Субтитры:**
- Lid говорит из нижней половины (виден в глазах Хэнка) → золотой текст у верхнего края нижней
  половины.
- Хэнк виден вверху → оранжевый у нижнего края верхней.
- Внутри сундука и Хэнк, и Pip говорят в нижней половине.

# 06. Shortest Scary Story…

| | |
|---|---|
| Длина | 4 с |
| Персонажи | Hank, Pip |
| Название | Shortest Scary Story… 👀 #shorts #animation |
| **Верх** | глаза Hank (сидит в кровати, ~1,3 блока) |
| **Низ** | **чьи-то** глаза с потолка, смотрят вниз на кровать. В конце ясно: это Pip |

**Идея.** Ночь. Хэнк сидит в кровати и вглядывается в темноту. Нижняя половина — чей-то взгляд
сверху. Капля розового желе падает Хэнку на лицо. Он смотрит вверх: на потолке Pip со светящимися
глазами. «Boo.»

**Приём.** Сам формат и есть загадка: зритель видит, что за Хэнком кто-то наблюдает, но не знает
кто. Ответ приходит в последнюю секунду. Короткий ролик пересматривают, значит, удержание выше 100 %.

## Мир: что построить

**Спальня Хэнка ночью** (`/time set 18000`):
- красная кровать;
- книжные полки;
- окно, в нём лунный свет;
- внутри **ни одного факела**, только слабый свет из окна.

Шейдеры дадут синюю темноту.

## Скриншоты

## Озвучка

```
HANK  [whisper, nervous]                ...Pip?
PIP   [whisper, sweet, creepy-cute]     Boo.
```

**Субтитры:**
- Хэнк виден внизу → его текст у верхнего края нижней половины.
- Pip виден вверху → у нижнего края верхней.
- Оба шёпотом, на 80 % размера.

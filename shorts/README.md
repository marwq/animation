# Шортсы: идеи и сценарии

Все шортсы сделаны по формуле, найденной в разборе
([analysis.md](../research/split-pov/analysis.md),
[breakdown-3-shorts.md](../research/split-pov/breakdown-3-shorts.md)):

- **экран разрезан пополам**, каждая половина — глаза одного из двух персонажей в один и тот же
  момент;
- **4–12 секунд**, одно место, одно действие, один поворот;
- **одна половина показывает то, чего не видит другой персонаж**: улику, ловушку, что-то за спиной;
- реплики короткие и быстрые, панчлайн — 1–3 слова;
- озвучка на английском.

Персонажи — в [cast/](../cast/README.md). Голос, звук и субтитры — в
[guide/voice-and-sound.md](../guide/voice-and-sound.md). Как снимать фоны — в
[guide/world-and-screenshots.md](../guide/world-and-screenshots.md).

На них отрабатывается весь процесс от озвучки до субтитров, потом можно брать сложнее.

## Ещё идеи (коротко)

| Идея | Чьи глаза | Поворот |
|---|---|---|
| **Hide and Seek (Take 2)** | Hank / Pip | Pip прячется в стене из розовой шерсти — идеальная маскировка. Хэнк ищет, устаёт, садится отдохнуть прямо на Pip. «Bloop.» |
| **Hide and Seek (Take 3)** | Pip / Hank | Прячется Хэнк — за тонким деревом, живот торчит с обеих сторон. Pip: «Hanky, I can see your tummy.» — «No you can't.» |
| **Hank's Statue** | Hank / Pip | **Одна статуя, две правды:** в глазах Хэнка величественный памятник ему самому, в глазах Pip — кривая куча булыжника. Lid предлагает купить «шедевр» за 64 изумруда. |
| **Pip Learns to Swim** | Hank / Pip | Хэнк: «Slimes can't swim!» Pip тонет, под водой глотает рыбу-фугу, раздувается шаром и улетает в небо. |
| **Hank's Trampoline (Take 1–3)** | Pip / Hank | Батут из слизи: каждый прыжок выше. Take 1 — Хэнк улетает за облака, Take 2 — застревает в дереве, Take 3 — приземляется на Lid. |
| **The Cookie Inspector** | Rocky / Pip | Pip выдаёт себя за «инспектора печенья», Rocky пускает его к банке. В конце внутри Pip двадцать печений: «Inspection… not finished.» |
| **Lid's Garage Sale** | Hank / Lid | Lid продаёт Хэнку «редкие вещи». В половине Lid видно: это вещи из сундука самого Хэнка. |
| **Shortest Sad Story…** | Pip / снаружи | 4 с: Pip весь день ждёт Хэнка у двери с подарком, солнце садится. В последнем кадре Хэнк спит дома, на кровати, в соседней комнате. |
| **Who Broke Granny's Window?** | Hank / Pip | Каждая половина показывает свою версию событий, и они противоречат друг другу. В конце: «Who's lying? 🤔» — комментарии решают. |
| **Rocky's Password (Take 2)** | Rocky / Granny | Теперь пароль «There's no password», и Granny не может попасть в собственный огород. |

## Серии

Серии растят просмотры: зритель досматривает, чтобы узнать, что будет дальше.
- **«Who ate…?»** — Pip съедает что-нибудь, улика видна внутри: 01, «Pip Ate the TNT», дальше
  «Who ate the cookies?», «Who ate the door?».
- **«Hide and Seek (Take N)»** — одна шутка, каждый раз с нарастанием.
- **«Lid's Deals»** — Lid обманывает кого-то нового: 04, 08, «Garage Sale».
- **«Shortest … Story…»** — 4 секунды, поворот в последнюю секунду.

## Упаковка (для всех)

- **Название:** крючок + «(Minecraft Animation) #shorts». Вопрос лучше всего:
  - «Who Ate Hank's Birthday Cake? 🎂 (Minecraft Animation) #shorts»;
  - «Which Chest Is the Mimic? 🤔 (Minecraft Animation Challenge) #shorts».
- **Описание:**
  ```
  Pip swears he didn't eat the cake... but you can see right through him 🎂

  A fan-made animation set in Minecraft. Subscribe for more Hank & Pip!
  #minecraft #animation #shorts
  ```
- **Закреплённый комментарий** с вопросом к зрителям: «Did you notice the blink at 0:02? 👀»,
  «Top or bottom? 👇».
- **Обложка:** кадр из середины ролика, где хорошо видны обе половины.

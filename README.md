# Персонажи — развороты (спереди / сбоку / сзади)

Все персонажи нарисованы в стиле первого референса: большая голова, простое лицо
(глаза-овалы, нос «уголком»), толстый чёрный контур, плоская заливка с одной тенью.
**Руки и ноги — палки.**

## Элли

![Разворот Элли](characters/ellie/png/turnaround.png)

- **Одежда:** красная майка без рукавов.
- **Волосы:** каштановые с рыжиной — боковой пробор, чёлка набок, пряди у лица,
  хвост на тёмной резинке.
- **Рюкзак:** чёрно-серый. Спереди лямки с пряжками и нагрудным ремешком, сбоку — рюкзак
  в профиль с боковым карманом, сзади — молния и передний карман.
- Веснушки на щеках.

## Джоэл

![Разворот Джоэла](characters/joel/png/turnaround.png)

- **Одежда:** рубашка цвета хаки без рукавов — воротник, планка с пуговицами, два
  нагрудных кармана с клапанами.
- **Голова:** короткие тёмные волосы, короткая борода с проседью и усы, густые брови.
- **Рюкзак:** коричневый. Спереди лямки с металлическими D-кольцами и пряжками, сбоку —
  клапан и боковой карман, сзади — клапан с двумя ремешками на пряжках.
- **Рост:** Джоэл выше Элли. Его холст 600×1100 вместо 600×1000, земля на том же отступе
  снизу, поэтому в одном масштабе рост соотносится правильно.

## Сара

![Разворот Сары](characters/sarah/png/turnaround.png)

- **Одежда:** розовая майка без рукавов.
- **Волосы:** светлое каре до подбородка, чёлка набок от пробора, пряди заправлены за уши.
- **Детали:** бусы с кулоном-зубом, как на фото; румянец и улыбка.
- **Рост:** немного ниже Элли — голова и тело примерно 94 % от неё, холст тот же 600×1000.

# Персонажи из Moho — каждый слой в PNG

Исходники лежат в `moho/*.moho`: риги с костями из Moho. Картинка-радуга для
радужного скелета лежит в `moho/Images/`. Каждый векторный слой выгружен
в отдельный PNG **на общем холсте персонажа**. У всех PNG одного персонажа одинаковый
размер, а часть нарисована ровно на своём месте. Положите файлы друг на друга по порядку
номеров, и руки, локти, колени встанут туда же, где они в Moho.

Всё снято в позе покоя (кадр 0 Moho). Кости в ней ничего не деформируют, поэтому каждая
часть выглядит так, как нарисована. Масштаб тот же, что в проекте: 1 единица Moho =
1000 px (кадр 2000×2000).

**skeleton verity small** — исправленный автором вариант (тело круглее, крылья отодвинуты): смотрит
влево, крыло со стороны взгляда — за телом, внизу. Прежний вариант сохранён как
`moho/skeleton verity small v1.moho` → `rigs/skeleton-verity-small-v1/`; ролики 1–26 используют его.

«Слоёв» — обычные слои без вариантов рта и глаз. У All verity color, child, lord и
skeleton verity big глаза — один слой `eye`, без вариантов.

**All verity color** — радужный скелет. В Moho каждая группа (рука, нога, тело, голова)
закрашена картинкой-радугой через маску. В PNG каждая часть уже радужная, с обводкой:
заливка части, поверх неё радуга, обрезанная по форме этой части, а сверху линии
(в Moho у этих слоёв включено «исключить линии из маски»). Верхушка позвоночника в слое
`hip` выходит за край картинки и осталась исходного цвета, как и в Moho: в собранном
персонаже её закрывает тело.

## Что лежит в папке персонажа

| Файл | Что это |
|---|---|
| `png/NN-слой.png` | слой на прозрачном фоне, холст общий для всего персонажа. `NN` — порядок отрисовки снизу вверх |
| `png/NN-mouth--вариант.png`, `png/NN-eyes--вариант.png` | варианты switch-слоя: у них общий номер `NN`, показывать нужно один |
| `svg/…` | те же слои в векторе |
| `preview.png` | персонаж целиком из тех же слоёв, с вариантами по умолчанию, как в Moho на кадре 0 |
| `bones.png` | то же с костями: синяя линия — кость, красный кружок — её сустав (точка поворота) |
| `variants.png` | все рты и глаза, каждый на лице на своём месте; красная рамка — вариант по умолчанию |

`leg left 1/2/3` — бедро, голень, стопа. `left`/`right` — как назвали в Moho.

## rig.json — для анимации

- `bones[]`: `base` — сустав (начало кости), `tip` — конец, `angle_deg` — угол на экране
  (0° = вправо, по часовой), `parent` — родительская кость, `drives` — какие слои она
  ведёт.
- `layers[]` и `switches[].children[]`: `png`, `order`, `bbox` (где на холсте нарисована
  часть) и привязка:
  - `bone` + `pivot` — кость слоя и её сустав. Поворачивать PNG нужно вокруг `pivot`,
    а дочерние кости и слои двигать вместе с родительской костью;
  - `binding: "rigid"` — слой целиком следует за одной костью, как в Moho;
  - `binding: "points"` — точки слоя в Moho привязаны к двум костям (`point_bones`).
    Например, у девочек `hand left 2` — предплечье с кистью, у лорда `leg left 3` —
    ботинок. Одним PNG такой слой может только повернуться за главной костью `bone`,
    сгиб внутри него не получится;
  - `binding: "flexible"` — слой гнётся по нескольким костям (`flexible_bones`, туловище
    девочек и лорда). В PNG он следует за корневой из них;
  - `binding: "none"` — слой не привязан ни к одной существующей кости.
- `switches[]`: `default` — вариант на кадре 0. `smart_bone` и `smart_bone_frames`
  показывают, какая умная кость (`mouth`, `eye`) переключает варианты в Moho и на каком
  кадре её действия стоит каждый вариант.
- `moho_frame.offset` переводит пиксели холста в пиксели кадра Moho 2000×2000:
  `кадр = холст + offset`.

**Замечание по ригу.** В `girl verity small` switch-слой `mouth` привязан к кости с номером 8
(счёт с нуля), а в файле всего 5 костей: похоже, слой скопирован из большой версии. Поэтому в
`rig.json` у её ртов стоит `binding: "none"`. Если в Moho рот не едет вместе с
головой, причина в этом: его нужно заново привязать к кости.

## Как пересобрать

```bash
python3 tools/moho_export.py                       # SVG + rig.json для всех файлов из moho/
python3 tools/moho_export.py "moho/fat verity small.moho"   # или только один
node tools/render_rigs.js                          # PNG (нужен Playwright, см. выше)
```

`tools/moho_export.py` читает `.moho` (zip с JSON Moho) без сторонних библиотек.
Кривые строятся так же, как в Moho: из кривизны, веса и поворота ручек каждой точки.
Формулы сверены с [описанием формата](https://github.com/vinhio/moho2svg), восстановленным
по экспорту самого Moho. Результат проверен наложением на превью, которое Moho сохраняет
внутри `.moho`.

# Анимация: Скелет против Лорда (25 секунд, v2)

`animations/skeleton-vs-lord/skeleton-vs-lord.mp4`: 1920×1080, 24 кадра/с, 600 кадров,
H.264, без звука. Сделано по гайду автора (`docs/animal_hospital_long.md`) и образцу
`05_fat_lord_girl.mp4`:
- никаких надписей, цифр, полосок здоровья и аватарок;
- размеры как в образце: шарик ~300 px, большие ~730 px от макушки до подошв, земля на y≈816;
- оба начинают маленькими и смотрят друг на друга; первые 4 секунды стоят неподвижно;
- большая версия появляется только после злости: жилка и пар → широкая ухмылка → золотые
  лучи, дрожь и рост → вспышка, серое облако дыма, тряска → большой стоит на месте шарика;
- ноги в три четверти: оба колена гнутся вперёд к носкам, стопы стоят ровно и не скользят;
- рука, которая должна быть перед телом, на этот момент поднимается над телом (или над
  соперником, когда бьёт), потом возвращается назад.

| Время | Что происходит |
|---|---|
| 0–4 с | Маленькие Лорд (слева) и Скелет (справа) стоят и смотрят друг на друга |
| 4–6.5 с | Лорд подпрыгивает ближе, приседает, дрожит и бьёт головой в живот |
| 6.5–8.6 с | Скелет кувырком отлетает, над ним звёздочки; Лорд смеётся |
| 8.6–11.7 с | Скелет злится и превращается в большого; Лорд пугается и потеет |
| 11.3–13.6 с | Большой Скелет подходит и с замаха шлёпает Лорда, тот кувырком улетает |
| 14.7–17.5 с | Лорд злится и превращается в большого; Скелет пугается |
| 17.5–19.5 с | Скелет бьёт, Лорд отскакивает назад — промах |
| 19.7–21.1 с | Лорд дальней рукой снимает шляпу и бросает: шляпа бьёт Скелета в лицо и возвращается на голову |
| 21.4–22.8 с | Лорд подходит и бьёт апперкотом, Скелет улетает за кадр, на месте — блеск |
| 22.8–25 с | Лорд идёт в центр, поворачивается к зрителю и поднимает руки буквой V. Победил Лорд |

## Как это сделано (движок v2)

- Направление тела берётся из рига: куда смотрят носки (у Лорда вправо, у Скелета влево).
  Колени всегда гнутся в сторону носков, локти — назад. Если персонаж повёрнут к сопернику
  другой стороной, рисунок зеркалится целиком, а не одна нога.
- Позы ставятся «поза на позу»: ключ держится, пока не начнётся переход к следующему
  (`Track.add(кадр, поза, ease, длительность)`), поэтому нет дрейфа и «дыхания».
- Стопы задаются точкой на земле. Шаг: опорная стопа стоит, вторая поднимается и
  переставляется, ноги почти прямые, подошвы ровно.
- Удар задаётся целью (`hitF: 1, hitFto: 'lord:cheek'`): кисть доходит до края лица
  соперника на длину руки. После кадра удара цель замирает (`hitFfix`), и рука не
  тянется за улетевшим соперником. `over: 'F'` рисует бьющую руку поверх соперника.
- `zF`/`zB: 'front'|'back'` поднимает руку над телом или убирает её за тело на время.
- `look` сдвигает глаза и рот к сопернику и чуть сужает голову (вид в три четверти).
- Дым, лучи, вспышка, пот, пар, жилка, звёздочки, пыль и блеск — в `animations/fx.js`.

| Файл | Что это |
|---|---|
| `animations/engine.js` | загрузка ригов, кости, IK, ключи «поза на позу», рисование |
| `animations/fx.js` | фон под Minecraft (небо, облака, трава, земля), эффекты |
| `animations/stage.js` | общая сцена драки: ключи, помощники движения, эффекты, сборка кадра |
| `animations/skeleton-vs-lord/scene.js` | сценарий по кадрам: позы, превращения, удары |
| `tools/render_anim.js` | рендер в MP4 (Chromium + ffmpeg) или отдельные кадры |

```bash
node tools/render_anim.js animations/skeleton-vs-lord                          # видео
node tools/render_anim.js animations/skeleton-vs-lord --still 6.5,12.5 --out /tmp/kadry   # кадры (секунды)
```

# Ролики 2–24

Все по одному шаблону: 25 с, 24 кадра/с, 1920×1080, только звуковые эффекты, первые 4 с
стойка, хотя бы один боец большой к 5-й секунде, победитель в центре. По просьбе автора
чаще большие девушки, и когда девушка становится большой — в неё влюбляются.

Общие приёмы — в `animations/stage.js`: `strike` (удар рукой с замахом), `kick`, `dodge`
(отскок назад), `duck` (нырок, не глубже 60 % ноги), `recoil`, `fallBack` (на спину), `flyOff`
(улёт с блеском), `victory`, `turn`, `love` (сердечки вместо глаз — центры глаз из
`animations/eyes.json`, его пишет `tools/eyes.py`), `blowKiss`. `transform(..., { love: 'кто' })`

## Звук (только эффекты, без музыки)

Звуки синтезируются в `tools/sfx.py` (numpy, без готовых сэмплов): взмах перед ударом,
удар, шлепок, «бонк», «ой!» того, кого ударили (у маленького выше, у большого ниже, у
каждого персонажа свой голос — `voice` в `cast`), батут, прыжок, приземление, падение после
отлёта, тяжёлое падение, шаги, «вжух» мимо, ветер от крыльев, дым, злость, заряд перед
превращением, рост, блеск, птички над головой, капля пота, испуг, сердечко, поцелуй,
влюблённость. Первые 4 секунды (стойка) — тишина.

Метки ставит сама сцена: помощники `hop`, `tumble`, `walk`, `transform` и эффекты добавляют
свой звук. Удар (`spark`) сам ставит взмах за 5 кадров, удар и «ой» у того, в кого попали;
отлёт (`tumble`) — свист, падение, отскок (и «ой» с `hurt: true`). Остальное —
`sfx(вид, кадр, {who|at|x, gain})`. Звук ставится в стерео по месту на сцене.
`tools/render_anim.js` после видео сводит звук в WAV и кладёт его в MP4.

```bash
python3 tools/sfx.py --demo /tmp/zvuki.wav                    # все звуки подряд
node tools/render_anim.js animations/girl-vs-skel --audio-only # пересвести только звук
node tools/render_anim.js animations/girl-vs-skel --mute       # видео без звука
```

Новое в движке для этого ролика: `splitFeet` (у Девочки стопа нарисована на слое голени —
слой режется по щиколотке, и стопа стоит ровно), `bendF/bendB` (локоть в другую сторону),
сердечки вместо глаз (`hearteyes`), летящие сердечки, ветер, быстрое превращение
(`transform(..., { fast: true })`).

// ... ключи по кадрам ...
ST.start(BIG);   // BIG — позы больших, после загрузки ригов

## Как это было сделано

- Каждый PNG-слой из `rigs/` едет за своей костью. Кость поворачивается вокруг своего
  сустава, а дочерние кости и слои едут вместе с ней. Поэтому локоть всегда остаётся
  на конце плеча, а колено на конце бедра.
- Руки и ноги ставятся через IK по двум звеньям: задаётся, где должна быть кисть или
  стопа, а углы в плече, локте, бедре и колене считаются сами. Колени всегда гнутся
  наружу, в прыжке и при ударе ногой колено идёт вверх. Локти смотрят вниз.
- Стопы задаются точкой на земле. Пока тело движется, стопа стоит на месте и не
  скользит. Приставной шаг переставляет ноги по очереди.
- Удар задаётся целью: кулак или стопа идёт к лицу соперника, где бы оно ни было в
  этот момент.
- Рты переключаются вариантами из switch-слоёв (`angry theeth`, `puzzlement`,
  `happy open mouth`, `Throw up`…), у Толстяка ещё меняются глаза (`angry`, `sad`).

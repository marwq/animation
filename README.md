# Персонажи — развороты (спереди / 3/4 / сбоку / сзади)

Элли, Джоэл и Сара нарисованы в стиле первого референса: большая голова, простое лицо
(глаза-овалы, нос «уголком»), толстый чёрный контур, плоская заливка с одной тенью.
**Руки и ноги — палки.** Девочка в худи сохраняет стиль своего референса — см. ниже.

## Элли

![Разворот Элли](characters/ellie/png/turnaround.png)

- **Одежда:** красная майка без рукавов.
- **Волосы:** каштановые с рыжиной — боковой пробор, чёлка набок, пряди у лица,
  хвост на тёмной резинке.
- **Рюкзак:** чёрно-серый. Спереди лямки с пряжками и нагрудным ремешком, сбоку — рюкзак
  в профиль с боковым карманом, сзади — молния и передний карман.
- Веснушки на щеках.

## Джоэл

![Разворот Джоэла](characters/joel/png/turnaround.png)

- **Одежда:** рубашка цвета хаки без рукавов — воротник, планка с пуговицами, два
  нагрудных кармана с клапанами.
- **Голова:** короткие тёмные волосы, короткая борода с проседью и усы, густые брови.
- **Рюкзак:** коричневый. Спереди лямки с металлическими D-кольцами и пряжками, сбоку —
  клапан и боковой карман, сзади — клапан с двумя ремешками на пряжках.
- **Рост:** Джоэл выше Элли. Его холст 600×1100 вместо 600×1000, земля на том же отступе
  снизу, поэтому в одном масштабе рост соотносится правильно.

## Сара

![Разворот Сары](characters/sarah/png/turnaround.png)

- **Одежда:** розовая майка без рукавов.
- **Волосы:** светлое каре до подбородка, чёлка набок от пробора, пряди заправлены за уши.
- **Детали:** бусы с кулоном-зубом, как на фото; румянец и улыбка.
- **Рост:** немного ниже Элли — голова и тело примерно 94 % от неё, холст тот же 600×1000.

## Девочка в худи

![Разворот девочки в худи](characters/hoodie_girl/png/turnaround.png)

- **Виды:** спереди, 3/4 и сбоку. Поза нейтральная — руки опущены вдоль тела, ноги
  прямо, лицо без эмоций, взгляд вперёд. В 3/4 и сбоку она повёрнута лицом влево от
  зрителя, поэтому видна её левая сторона — с ухом и заколкой, как на референсе.
- **Стиль — как на референсе:** тонкий контур, плоская заливка без теней, большие
  круглые глаза, руки и ноги с толщиной (не палки), рост ≈ 4,6 головы.
- **Волосы:** тёмное каре с волнистой полосой серых бликов, пробор чуть правее центра.
  Справа (её левая сторона) волосы заправлены за ухо и торчат завитком под ним, там же
  зелёная заколка; слева закрывают ухо и топорщатся прядкой.
- **Одежда:** серо-голубое худи на молнии со светлым капюшоном-воротником, шнурками,
  манжетами и поясом, значок на груди слева; зелёная плиссированная юбка; белые гольфы
  до колена; массивные коричневые ботинки на серой подошве.
- **Холст:** 600×1100, земля y=1052 — как у Джоэла.

## Файлы

| Путь | Что это |
|---|---|
| `characters/<имя>/front.svg`, `side.svg`, `back.svg` | отдельные виды, вектор (у девочки в худи вместо `back.svg` — `three_quarter.svg`) |
| `characters/<имя>/turnaround.svg` | лист-разворот: три вида, направляющие по высоте, палитра |
| `characters/<имя>/png/*.png` | те же файлы в PNG ×2; отдельные виды — на прозрачном фоне |
| `tools/ellie.py`, `tools/joel.py`, `tools/sarah.py`, `tools/hoodie_girl.py` | формы и палитра каждого персонажа |
| `tools/charlib.py` | общие функции: примитивы SVG, лист-разворот |
| `tools/build_characters.py` | сборка SVG |
| `tools/render.js` | рендер SVG → PNG |

У Элли, Джоэла и Сары руки и ноги — одиночные линии; первая точка пути — плечо или
бедро, её удобно брать за точку поворота. У девочки в худи руки и ноги — залитые формы:
рукав (`arm-*`) и кисть (`hand-*`), нога, гольф и ботинок — отдельные группы; ухо
нарисовано поверх волос, потому что волосы заправлены за него.

## Как пересобрать

```bash
python3 tools/build_characters.py        # SVG всех персонажей (или: ... hoodie_girl)

# PNG: нужен Node.js и Playwright (ставится один раз)
npm i --no-save playwright && npx playwright install chromium
node tools/render.js                     # PNG ×2 (или: node tools/render.js 2 sarah)
```

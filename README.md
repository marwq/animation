# Персонажи — развороты (спереди / сбоку / сзади)

Все персонажи нарисованы в стиле первого референса: большая голова, простое лицо
(глаза-овалы, нос «уголком»), толстый чёрный контур, плоская заливка с одной тенью.
**Руки и ноги — палки.**

## Элли

![Разворот Элли](characters/ellie/png/turnaround.png)

- **Одежда:** красная майка без рукавов.
- **Волосы:** каштановые с рыжиной — боковой пробор, чёлка набок, пряди у лица,
  хвост на тёмной резинке.
- **Рюкзак:** чёрно-серый. Спереди лямки с пряжками и нагрудным ремешком, сбоку — рюкзак
  в профиль с боковым карманом, сзади — молния и передний карман.
- Веснушки на щеках.

## Джоэл

![Разворот Джоэла](characters/joel/png/turnaround.png)

- **Одежда:** рубашка цвета хаки без рукавов — воротник, планка с пуговицами, два
  нагрудных кармана с клапанами.
- **Голова:** короткие тёмные волосы, короткая борода с проседью и усы, густые брови.
- **Рюкзак:** коричневый. Спереди лямки с металлическими D-кольцами и пряжками, сбоку —
  клапан и боковой карман, сзади — клапан с двумя ремешками на пряжках.
- **Рост:** Джоэл выше Элли. Его холст 600×1100 вместо 600×1000, земля на том же отступе
  снизу, поэтому в одном масштабе рост соотносится правильно.

## Сара

![Разворот Сары](characters/sarah/png/turnaround.png)

- **Одежда:** розовая майка без рукавов.
- **Волосы:** светлое каре до подбородка, чёлка набок от пробора, пряди заправлены за уши.
- **Детали:** бусы с кулоном-зубом, как на фото; румянец и улыбка.
- **Рост:** немного ниже Элли — голова и тело примерно 94 % от неё, холст тот же 600×1000.

## Файлы

| Путь | Что это |
|---|---|
| `characters/<имя>/front.svg`, `side.svg`, `back.svg` | отдельные виды, вектор |
| `characters/<имя>/turnaround.svg` | лист-разворот: три вида, направляющие по высоте, палитра |
| `characters/<имя>/png/*.png` | те же файлы в PNG ×2; отдельные виды — на прозрачном фоне |
| `tools/ellie.py`, `tools/joel.py`, `tools/sarah.py` | формы и палитра каждого персонажа |
| `tools/charlib.py` | общие функции: примитивы SVG, лист-разворот |
| `tools/build_characters.py` | сборка SVG |
| `tools/render.js` | рендер SVG → PNG |

`front-arm-left` находится справа от зрителя.

## Как пересобрать

```bash
python3 tools/build_characters.py        # SVG всех персонажей (или: ... sarah)

# PNG: нужен Node.js и Playwright (ставится один раз)
npm i --no-save playwright && npx playwright install chromium
node tools/render.js                     # PNG ×2 (или: node tools/render.js 2 sarah)
```

## POV — «What if you kept sinking forever?», первые 3 минуты

![Первые три минуты](pov/renders/sinking_0-3min.mp4)

Ролик от первого лица, одним непрерывным кадром: герой стоит на крышке люка посреди Таймс-сквер,
крышка уходит вниз — и он погружается сквозь Нью-Йорк, всё быстрее. Камера ведёт себя как голова:
повороты начинаются и заканчиваются плавно (сплайн по ключам + пружина), корпус доворачивается
следом; руки, ноги и браслет-глубиномер появляются по ходу действия, суставы гнутся только в
анатомически возможную сторону (колено — назад, локоть — к груди, кисть — без перекручивания).
Одежда: зелёная куртка, голубая футболка, синие брюки, белые кеды с зелёной полосой.

Сверху слева — крупный блок глубины: место, число, сравнение («глубже, чем…»), что дальше и сколько
до него; справа — шкала пути до другой стороны Земли; внизу — подписи на мягкой тёмной подложке.
Закадрового голоса нет: подписи, своя эмбиент-музыка и объёмный звук, привязанный к картинке.

| Время | Глубина | Что в кадре |
|---|---|---|
| 0:00–0:12 | 0 м | Таймс-сквер: экраны, One Times Square, такси и автобусы, красные ступени, Эмпайр-стейт и Крайслер, толпа, голуби |
| 0:12–0:22 | 0–6.5 м | крышка люка лязгает и уходит вниз, шахта со скобами, взгляд на круг неба; коллектор с водой, струёй и крысой |
| 0:22–0:36 | 6.5–12 м | грунт: газовая труба, водопровод, паропровод в полоску, кабели, оптоволокно |
| 0:36–0:47 | 12–16.6 м | тоннель метро: светофоры, контактный рельс, поезд из шести вагонов в метре от лица |
| 0:47–1:55 | 16.6–183 м | манхэттенский сланец: гранаты, кварцевые жилы, трещина с грунтовой водой, тёмные дайки, ржавые зоны |
| 1:55–2:00 | 183–190 м | внутри водовода, залитого водой |
| 2:00–2:26 | 190–380 м | сланец, смятый в складки; разгон |
| 2:26–3:00 | 380–1 137 м | фордемский гнейс (больше миллиарда лет), высоты Эмпайр-стейт, One WTC, Бурдж-Халифы; «Один километр. Осталось 12 741» |

| Путь | Что это |
|---|---|
| `pov/scene.json` | раскадровка: глубина, повороты головы и корпуса, позы рук, подписи, сравнения и вехи, слои под землёй, поезд — общая для картинки и звука |
| `pov/timeline.js` | читает `scene.json` и сглаживает ключи |
| `pov/body.js` | тело героя: корпус, ноги, руки с IK на два сустава, браслет |
| `pov/nyc.js`, `pov/landmarks.js`, `pov/fleet.js`, `pov/crowd.js` | Таймс-сквер: кварталы, экраны без брендов, достопримечательности, машины, люди, голуби |
| `pov/manhole.js` | крышка люка, шахта, кирпичный коллектор |
| `pov/underground.js` | грунт с трубами и тоннель метро с поездом |
| `pov/rock.js` | сланец и гнейс вокруг героя, гранаты, жилы, трещина с водой, водовод; смаз текстуры на скорости |
| `pov/hud.js`, `pov/hud.css` | надписи поверх кадра |
| `pov/audio.py` | музыка и звук: всё синтезируется, без чужих записей; громкость −14 LUFS; дорожки кешируются в `pov/out/stems` |
| `pov/render.js` | рендер кадров (или куска) в headless Chromium, кадры для проверки, виды на героя со стороны (`--debug`) |

| `pov/renders/` | готовые ролики: первые 3 минуты и прошлые тесты стиля |

```bash
npm i --no-save playwright three @fontsource/space-grotesk @fontsource/jetbrains-mono
pip install numpy scipy
python3 pov/audio.py                         # pov/out/audio.wav (AUDIO_ONLY=deep пересчитает одну дорожку)
node pov/render-all.js 3                     # pov/out/style_test.mp4, 60 к/с, три браузера параллельно
node pov/render.js --stills 59,116.8         # отдельные кадры для проверки
node pov/render.js --debug 75.5 front,side   # поза героя со стороны
```
